# Gen-AI_Footprint_Lab
GenAI Footprint Lab is a Streamlit app that estimates the energy, carbon and water footprint of generative AI across 9 regions, tests ways to cut it, and shows the uncertainty. AI Studio adds a live LLM (Claude, OpenAI or Gemini): grounded advisor, prompt optimizer with LLM judge, executive memos. Works in demo mode without an API key.
